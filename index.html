About & Engineering Philosophy

Hello! I'm Vidya, a Computer Engineering student driven by understanding how modern software systems run on physical hardware. I believe the most robust software engineers possess empathy for both the silicon & cache line and the end-user interface.

My coursework in operating systems and computer architecture gives me deep intuition into concurrency hazards, memory layouts, virtual paging, and network bottlenecks. I leverage this foundation daily to build responsive, microservice-backed full-stack web applications that remain rock-solid under high traffic loads.
